**Plus-Minus Task**

Plus-Minus Task is a cognitive task to measure shifting performance, as a component of executive function, showing the flexibility to switch between task and rules.
The condition used in this task is mathematical operation. Participant is asked to shift between addition, subtraction, and alternating on the each task blocks.
The output from this task contains reaction time and accuracy, as the base measurements for switching cost.

This task is adapted from Demeyer et al. (2026) with the instruction translated to Bahasa Indonesia. The task is built using inline script (Python) in OpenSesame software.
